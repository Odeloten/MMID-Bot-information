# MMID Bot & Skyza — Privacy Policy
_Last updated: 19 February 2026_

---

## 1. Overview
This Privacy Policy explains how the MMID Bot and the associated website (skyza.app) process information.

The Discord bot itself does not store user messages or server content.  
However, certain information may be processed if you choose to verify via skyza.app.

---

## 2. Data Processed by the Discord Bot

When using `/mmid`:
- A Minecraft username is provided by the user.
- This value is processed temporarily to generate the MMID card.
- It is not stored in any database.

The bot does not log or store:
- Discord message content
- Guild or server data
- Interaction history
- IP addresses

---

## 3. Data Processed by skyza.app (Verification System)

If you choose to verify via skyza.app, the following data may be processed:

- Discord ID  
- Discord username  
- Discord email address (if included in Discord OAuth scope)  
- Verification status  
- Report submissions  

This data is used solely for:
- Preventing abuse and spam
- Enabling global `/report` access
- Associating reports with verified accounts

---

## 4. Data Storage

Verification-related data may be stored securely in a private database.

Data is not sold, shared, rented, or used for advertising purposes.

---

## 5. Third-Party Services

The system may interact with:

- Discord OAuth (for authentication)
- Google Sheets (MMID data source)
- Crafatar (skin rendering)

These services operate under their own privacy policies.

---

## 6. Data Retention & Deletion

Verification data is retained only as long as necessary to maintain account integrity and prevent abuse.

Users may request removal of their stored verification data by contacting the bot owner via Discord.

---

## 7. Security

The system is privately hosted and protected using standard security practices.  
Access to stored data is restricted to the bot owner.

---

## 8. Contact

For privacy-related inquiries or data deletion requests, contact the bot owner via Discord.
